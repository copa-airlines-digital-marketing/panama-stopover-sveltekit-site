# Project instructions

## GitHub authentication

- Use Git Credential Manager with standard `git` commands for GitHub authentication and pushes.
- Do not require or use GitHub CLI (`gh`) unless the user explicitly requests it.

## Sunsama

- Use the Sunsama channel `Events Integration` for every task in this project.
- Give each task a short, descriptive name, record the real elapsed time, and mark it completed when the work is finished.
